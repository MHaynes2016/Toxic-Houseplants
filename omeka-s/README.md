# Omeka S Application

This directory contains the Omeka S application files for the Toxic Houseplants project.

## Installation
Follow the [official Omeka S installation guide](https://omeka.org/s/docs/user-manual/install/) to set up the application.

## Configuration
- Database configuration should be placed in `config/database.ini` (not version controlled)
- Uploaded files will be stored in the `files/` directory (not version controlled)
