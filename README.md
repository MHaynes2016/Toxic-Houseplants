# Toxic Houseplants Repository (Omeka S Project)

## Purpose
To document toxic houseplants that are commonly found in North America, focusing on:
- Toxicity level (low/moderate/high)
- Toxic principles (oxalates, cardiac glycosides, cyasin, etc.)
- Affected species (cats, dogs, humans)
- First Aid guidance and credible source links

## Structure
- **omeka-s/** - Omeka S application files
- **files/** - Uploaded media files (not version controlled)
- **metadata/** - CSV data files and resource templates
- **docs/** - Assignment submission and documentation

## Getting Started
1. Clone this repository
2. Review the metadata templates in `metadata/`
3. Consult the documentation in `docs/`

## Data Fields
Each toxic houseplant entry includes:
- Common name
- Scientific name
- Toxicity level (low/moderate/high)
- Toxic principles
- Affected species
- Symptoms
- First aid recommendations
- Source links
