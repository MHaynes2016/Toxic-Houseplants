# Metadata Directory

This directory contains CSV data files and resource templates for the Toxic Houseplants project.

## Files
- **toxic_houseplants_template.csv** - Template for entering new toxic houseplant data
- **resource_template.json** - Omeka S resource template definition

## CSV Structure
Each row represents a toxic houseplant with the following fields:
- Common Name
- Scientific Name
- Toxicity Level (low/moderate/high)
- Toxic Principles
- Affected Species (cats/dogs/humans)
- Symptoms
- First Aid
- Source Links

## Usage
1. Use the template CSV to record toxic houseplant data
2. Import the CSV into Omeka S using the CSV Import module
3. Apply the resource template for consistent metadata structure
